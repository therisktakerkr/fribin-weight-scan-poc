    카메라·OCR 캡처 화면은 인식 처리에만 잠깐 쓰이고 저장·전송되지 않습니다. 어떤 방식으로 인식하든 자동 저장/자동 확정 없이 직원이 "이 중량으로 확정"을 눌러야 반영됩니다. 브랜드·품목·바코드 번호를 미리 등록하는 구조는 없습니다. 로그인, 거래처/상품 선택, 서버 저장, Excel 연동, DB, GTIN 매핑 기능은 이 POC에 없습니다(의도적으로 제외).
    OCR은 화면 중앙의 작은 사각형(라벨의 "중량 X kg" 한 줄) 안쪽만 인식하며, 서로 다른 전처리 결과 중 최소 2개 이상이 일치할 때만 "권장" 후보로 표시합니다. 일치하지 않으면 "불확실"로 표시하고 직원이 후보를 직접 고르거나 다시 촬영하거나 직접 입력해야 합니다 — 자동 확정은 어떤 경우에도 없습니다.
    바코드 인식: zxing-wasm v3.1.2 · OCR(보조, 영어+한국어): tesseract.js v7.0.0 (둘 다 오픈소스, 로컬 실행, 외부 전송 없음)
